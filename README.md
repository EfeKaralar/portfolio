# Alp Karalar Portfolio (Static Website)

This project has been converted from a React/Next.js app to a static website while preserving the same content and visual style.

## Stack

- HTML (`index.html`)
- CSS (`styles.css`)
- Vanilla JavaScript (`script.js`)

## Run locally

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Deployment

This is now a static site and can be deployed directly to GitHub Pages, Netlify, Cloudflare Pages, or any static host.

## Contact behavior

The contact flow now uses a direct email action via:

`mailto:karalar.alpefe@gmail.com`

No server/API route is required.
